# Bioinformatica-1


## Tarea de la sesión 1

El capítulo-video que yo escogí es el 9: "How Do We Locate Disease-Causing Mutations?
Combinatorial Pattern Matching".

El capítulo habla sobre el decrecimiento del precio de las lecturas de DNA, 
esperando que llegue a menos de 1000 dolares; así como la posibilidad de 
leer tantos genomas que en un momento, para casos clínicos, solo encontrar 
diferencias con un modelo, ahorrando tiempo.

Me parece muy intersante cómo las herramientas biotecnológicas se han 
desarrollado tanto para tener un boom en el precio de proceso que al 
principio eran de las cosas más caras que pudiese haber.
No se si creo tanto en  el hecho de tener un modelo único, porque la 
cantidad de diversidad en fenotipo y genotipo en la población humana me 
parece muy interesante, pero también significa que podemos ver as
diferencias que había con individuos antiguos.
